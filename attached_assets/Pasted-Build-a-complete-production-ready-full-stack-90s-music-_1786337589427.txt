17. BACKGROUND AUDIO PLAYBACK

This is critical.

After the user has manually started playback:

The application should NOT intentionally pause audio when:

User changes browser tab
Browser window loses focus
Browser is minimized
Page becomes hidden
Phone screen is locked

Do NOT implement:

if (document.hidden) {
  audio.pause();
}

Remove any such behavior.

Use a persistent <audio> element.

Do NOT attempt to bypass browser autoplay restrictions.

The first playback must require user interaction.

After playback has started, allow the browser/device to continue playback according to its supported media policies.
